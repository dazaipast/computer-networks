# Порты и флаги

Задание: три снимка Wireshark. Два кадра TCP с разными флагами и один кадр UDP.

## 1. TCP, флаги PSH и ACK

![TCP PSH ACK](<Снимок экрана 2026-10-18 172250.png>)

Сервер `194.87.149.228` отвечает с порта 443 (HTTPS) клиенту `192.168.0.198` на порт 4886. В заголовке TCP флаги `0x018`: PSH и ACK. PSH показывает, что в сегменте есть данные для приложения, ACK подтверждает уже принятые байты. Номер последовательности 24004, номер подтверждения 1556, окно 10853.

## 2. TCP, флаг ACK

![TCP ACK](<Снимок экрана 2026-10-18 172316.png>)

Клиент `192.168.0.198` со своего порта 26762 подтверждает данные сервера `194.87.149.228:443`. Здесь другой набор флагов: только ACK (`0x010`). Полезной нагрузки нет, номер последовательности и следующий номер совпадают (561). Номер подтверждения 5446282, окно 511.

## 3. Третий снимок

![TCP с данными](<Снимок экрана 2026-10-18 172606.png>)

На третьем снимке снова TCP, не UDP. Сервер `194.87.149.228:443` передаёт данные клиенту `192.168.0.198:26762`. Флаг тот же ACK (`0x010`), но сегмент уже с данными: номер последовательности 2054256, следующий номер 2055704, то есть 1448 байт. В списке пакетов рядом видны повторные подтверждения и быстрая повторная передача.
